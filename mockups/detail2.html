perch

A tray app for one PC that shows the current state of everything its owner is working on, so a project can be picked up where it was left. Git repositories with their uncommitted and unpushed work, branches, remotes and CI; each project's roadmap; recent Claude Code sessions; recently played Steam games.

Everything on screen is read from the machine or from GitHub, Forgejo and Steam. Nothing is entered by hand and nothing is stored beyond the last scan.

Tauri 2, Rust backend, React frontend. Built for one Linux machine: Arch Linux, KDE Plasma 6 on Wayland.

Requirements and decisions: docs/spec.md. Parked work: docs/roadmap.md.

Status: scanner proof of concept. pnpm scan gathers raw facts into .scan/raw/ and aggregates them into .scan/snapshot.json.

Roadmap

Work identified and not done. Each item has its own heading. Remove items as they land.

First build

Scaffold and the sources in the spec. The order is for the build session to decide; the spec is the end state.

Claude Code integration

Six routes were identified, in rising cost, and all are parked until the base exists.

  • Show the last few user messages of the newest session on the project detail view.
  • Launch from a tile: a terminal running claude --resume on the newest session.
  • Hooks: a session end hook writes a one-line "where this stopped", a session start hook reads it back.

Forge issues source

Tickets from GitHub and Forgejo as a work source beside the in-repo roadmap, feeding the bubble's chips and the detail page.
